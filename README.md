# Curso em Vídeo de Javascript

## Quem é Gustavo Guanabara?

**Gustavo Guanabara** é um professor de tecnologia, educador e criador de conteúdo brasileiro, amplamente reconhecido por fundar o Curso em Vídeo, uma das principais iniciativas de ensino gratuito de programação e tecnologia do Brasil.

- **Trajetória:** Com formação em Tecnologia da Informação e vasta experiência lecionando no Rio de Janeiro (incluindo instituições como a FAETEC), atua na educação técnica há mais de duas décadas.
- **O [Curso em Vídeo](https://www.youtube.com/@cursoemvideo):** Lançado em 2013 no YouTube, o projeto nasceu com a proposta de democratizar o acesso ao ensino de TI, oferecendo cursos completos, estruturados e gratuitos para quem quer aprender do zero.
- **Principais Conteúdos:** Ficou famoso por suas formações para iniciantes em Algoritmos, Python, HTML5 e CSS3, JavaScript, Java, PHP, Hardware e Git/GitHub.
- **Didática:** Sua metodologia é marcada pela linguagem simples, uso de analogias do dia a dia, recursos visuais e uma estrutura modular pensada para manter o aluno motivado.


## Curso Em Vídeo de Javascript

O **Curso de Javascript** do canal [Curso em Vídeo](https://www.youtube.com/@cursoemvideo) é uma formação 100% gratuita, moderna e prática, criada pelo professor **Gustavo Guanabara** para ensinar desde os conceitos básicos até o desenvolvimento de sites profissionais, elegantes e totalmente responsivos.

Totalmente reformulado para trazer as melhores práticas da web moderna, o curso conta com material de apoio completo, livros digitais com códigos QR, repositórios no GitHub com exercícios e projetos práticos do mundo real.
